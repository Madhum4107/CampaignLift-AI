# CampaignLift AI

End-to-end uplift-modeling portfolio project for evaluating and ranking marketing campaign targets using estimated incremental response.

## Project location

The application currently lives in the `uplift-modeling-main/` subfolder.

- [Full project documentation](uplift-modeling-main/README.md)
- [Application source](uplift-modeling-main/)
- [Backend](uplift-modeling-main/backend/)
- [Frontend](uplift-modeling-main/frontend/)
- [Tests](uplift-modeling-main/tests/)

## Quick start

Clone the repository, then enter the application folder:

```bash
git clone https://github.com/Madhum4107/CampaignLift-AI.git
cd CampaignLift-AI/uplift-modeling-main
```

Follow the backend, frontend, training, test, and Docker setup instructions in the [project README](uplift-modeling-main/README.md).

## Modeling note

The project uses uplift modeling to estimate treatment-effect rankings. These are model estimates, not guaranteed campaign outcomes or causal explanations for individual customers. Review the detailed README for evaluation setup, assumptions, and limitations.
